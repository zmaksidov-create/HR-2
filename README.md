# HR Академия TM 2.0 — полный учебный курс

## Содержание
- 7 модулей, 21 учебный урок;
- 20 вопросов в банке промежуточного экзамена (10 случайных на попытку);
- тренажёр собеседования с 8 вопросами;
- справочник учебных шаблонов и чек-листов;
- сохранение прогресса и лучшего результата на устройстве;
- автономная работа после установки (интернет для работы приложения не требуется).

## Сборка APK
1. Установите Android Studio: https://developer.android.com/studio
2. Распакуйте архив и откройте папку проекта.
3. Дождитесь Gradle Sync; при необходимости установите Android SDK 35.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Это проект для debug-сборки. Для распространения создайте подписанную release-сборку через Build → Generate Signed Bundle / APK.
